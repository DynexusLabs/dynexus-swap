# Getting help

- **Usage questions and ideas:** open a [GitHub Discussion](https://github.com/DynexusLabs/dynexus-swap/discussions) if enabled,
  otherwise a [feature request](https://github.com/DynexusLabs/dynexus-swap/issues/new?template=feature_request.yml).
- **Bugs:** open a [bug report](https://github.com/DynexusLabs/dynexus-swap/issues/new?template=bug_report.yml) with steps to
  reproduce and the network or version you used.
- **Security issues:** never in public. See [SECURITY.md](SECURITY.md).

This is an open-source testnet project maintained on a best-effort basis; there is no
service-level agreement.
