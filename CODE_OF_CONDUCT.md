# Code of conduct

We want this project to be a welcoming place to work on, for everyone.

## Expected behaviour

- Be respectful and assume good intent. Disagree with ideas, not people.
- Give and accept feedback on code constructively.
- Keep discussions on topic and free of harassment, discrimination, personal attacks,
  or publishing other people's private information.

## Unacceptable behaviour

Harassment, insults, sexualised language or imagery, threats, doxxing, spam, and
anything else a reasonable person would consider inappropriate in a professional setting.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests, and may block people
who do not follow this code. To report a problem, use the private reporting option on the
repository's **Security** tab (https://github.com/DynexusLabs/dynexus-swap/security/advisories/new) and mention it is a
conduct report. Reports are handled in confidence.

This code applies in all project spaces: the repository, its issues, pull requests and
discussions.
